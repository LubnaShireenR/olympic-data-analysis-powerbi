# Olympic Data Analysis using Power BI

## Project Overview

This project analyzes Olympic Games data using Microsoft Power BI.
The dashboard provides visual insights into medal distribution, sports,
athlete performance, and the evolution of the Olympic Games over time.

## Objectives

The main objectives of this project are:

- Analyze Gold, Silver, and Bronze medal distribution across countries
- Identify sports contributing the highest number of medals
- Identify top-performing and repeat medal-winning athletes
- Analyze the evolution of Olympic Games in terms of sports, athletes,
  and participating nations

## Tools Used

- Microsoft Power BI
- Microsoft Excel

## Dataset

The dataset contains Olympic-related information including:

- Athlete Name
- Age
- Country
- Sport/Game
- Year
- Gold Medals
- Silver Medals
- Bronze Medals
- Total Medals

## Dashboard Pages

### Page 1 - Overall Medal Analysis

This page analyzes the overall distribution of Gold, Silver, and Bronze
medals across countries.

Visualizations include:

- Medal Distribution by Country
- Medal Performance Over Time
- Gold Medals by Country

### Page 2 - Sports Analysis

This page analyzes which sports contribute the highest number of medals
globally and across countries.

Visualizations include:

- Total Medals by Sport
- Medals by Sport and Country
- Sports Participation Over Time

### Page 3 - Athlete Performance Analysis

This page focuses on top-performing athletes and repeat medal winners.

Visualizations include:

- Most Decorated Athletes
- Athletes with Medals Across Olympics
- Average Age of Medal Winners

### Page 4 - Olympic Games Evolution

This page analyzes how the Olympic Games have evolved over time.

Visualizations include:

- Countries Participating Over Time
- Number of Sports Over Time
- Sports Growth by Year
